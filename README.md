# CAMLab

A virtual laboratory for Applied Mathematics.

CAMLab helps students and researchers explore differential equations, perturbation methods, numerical methods, dimensional analysis, and mathematical modelling through interactive computation and visualization.

## Features

### Version 1
- Numerical ODE Solver
- Perturbation Analysis
- Error Visualization
- Breakdown Detection
- Interactive Graphs

### Planned Features
- PDE Visualizer
- Buckingham Π Assistant
- Optimal Control Simulator
- Numerical Methods Comparison
- AI-Powered Mathematical Tutor

## Tech Stack

### Frontend
- React
- TypeScript
- TailwindCSS
- Plotly

### Backend
- FastAPI
- SymPy
- NumPy
- SciPy
